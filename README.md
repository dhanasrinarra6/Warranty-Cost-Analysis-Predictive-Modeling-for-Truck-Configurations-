# 🚚 Warranty Cost Analysis & Predictive Modeling for Truck Configurations

An analytics hackathon project focused on understanding warranty cost drivers across truck configurations using statistical testing, feature importance, and Random Forest modeling.

🏆 **3rd Place — Analytics Hackathon**

## 📌 Project Context

Warranty costs can vary across product configurations. This project investigates which configuration variables are associated with warranty costs and explores how machine learning can support cost estimation.

## 🎯 Objectives

- Identify variables associated with warranty costs
- Use statistical testing to investigate important factors
- Build a Random Forest model for predictive analysis
- Examine feature importance to understand potential cost drivers

## 🔍 Analysis Approach

1. Cleaned and prepared the warranty dataset
2. Performed exploratory analysis
3. Applied statistical testing to investigate relevant variables
4. Built a Random Forest model
5. Evaluated feature importance
6. Used the model for warranty-cost prediction

## 🧰 Tools & Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Statistical Testing
- Data Visualization

## 📊 Results

The project identified variables associated with warranty costs and used feature importance to investigate which factors contributed most to the model’s predictions.

The repository does not currently report a numerical model-performance metric, so no unsupported accuracy or error value is presented here.

## 💼 Business Relevance

The analysis demonstrates how statistical methods and predictive modeling can be combined to investigate **cost drivers and configuration-level risk**. These findings can support further analysis of product configuration, warranty planning, and cost-management decisions.

## 🏆 Achievement

**3rd place in an analytics hackathon.**

## ⚠️ Project Scope

This was completed as a **hackathon project**. The findings are intended to demonstrate the analytical approach and should be validated further before being used for operational or product decisions.
